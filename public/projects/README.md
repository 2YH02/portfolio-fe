# Original conceptual project covers

These are preserved alternatives. The current active set and prompts are documented in [REFINED-COVERS.md](./REFINED-COVERS.md).

## Final prompts

### pullup-cover.webp

Use case: stylized-concept. Asset: landscape 16:9 developer portfolio project cover, premium restrained editorial 3D illustration. Near-black #0a0a0a background, frosted glass, subtle film grain, precise blue and indigo accent light, generous breathing room. No text, letters, numbers, logos, watermarks, charts or fake screenshots. Single cohesive scene, crisp at thumbnail size. Subject: an isometric miniature urban street map floating as a dark glass slab, three small glowing blue location pins and a sculptural stainless steel outdoor pull-up exercise bar as the main focal object. A quiet geographic discovery service, refined architectural model, believable materials. Centered composition.
